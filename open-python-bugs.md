# Open Python bugs found by the C++ port (provisional)

Saved 2026-10-15 at Jeff's request so these are not lost. **Provisional: not re-checked against the code.** Each row is a record written by a porter or reviewer during the port (waves 1 to 10, ending at 4e92d36), copied as recorded. Statuses may be stale (a later wave may have fixed one), several rows can describe the same bug, and line numbers are as of the wave that wrote them.

The retrospective deduplicated these to **89 open bugs**, grouped into Correctness entries B1 to B15, of which the C++ reproduces 52, gets 29 right, and 8 are not established. That grouping and the per-entry table are in the retrospective: https://claude.ai/artifact/3AM3i4rVnF8WsyZQpBKZNM (sections "The Python bugs the port found" and "Correctness: the open bugs, ranked"), and in retro/parts/60_bugs.md and retro/parts/70_B_ideas.md on this branch.

Rows: 107 records (103 marked open, 4 marked n/a). Full records, with each one's evidence, are in records/python-bug.json; "#" is the record's index there. The 43 records marked fixed are not listed.
